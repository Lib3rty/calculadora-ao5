🧮 FUNCIONES DE CÁLCULO

timeCalculator.js incluye:

1. convertToMs(mm, ss, ms)           → Convierte a milisegundos
2. convertFromMs(totalMs)            → Convierte de milisegundos
3. calculateAverage(times[])         → Calcula promedio (PRINCIPAL)
4. formatTime(mm, ss, ms)            → Formatea para UI
5. isValidTime(mm, ss, ms)           → Valida rangos
6. areAllTimesComplete(times[])      → Verifica completitud

Algoritmo:
  Input: 5 tiempos
  → Ordena y encuentra min/max
  → Elimina ambos
  → Promedia los 3 restantes
  → Output: Resultado formateado + índices removidos

📋 FLUJO DE USO

1. Ingresa 5 tiempos (MM:SS.MS)
2. Presiona "Calcular Promedio"
3. Ve Scorecard con resultados
   - Tiempos eliminados (gris)
   - Tiempos usados (verde)
   - Promedio final (azul)
4. Opción "Nueva Scorecard" para comenzar de nuevo
5. Datos se guardan automáticamente
